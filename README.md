# Статистический анализ подписки GoFast

Портфолио-проект по продуктовой аналитике сервиса аренды самокатов. Цель — оценить различия между тарифами `Free` и `Ultra`, проверить продуктовые гипотезы и сформулировать рекомендации по продвижению подписки и промоакциям.

## Главные результаты

- После проверки телеметрии исключены 95 поездок (0,53%) с невозможной скоростью свыше 30 км/ч: все они длились 0,5 минуты при дистанции 4–7 км.
- Средняя длительность поездки на уровне пользователя у `Ultra` — 18,57 минуты, у `Free` — 17,53 минуты. Разница 1,05 минуты, 95% ДИ `[0,86; 1,24]`, скорректированный p-value `2,09e-26`, Hedges' g `0,56`.
- Средняя пользовательская дистанция `Ultra` — 3113 м, 95% ДИ `[3091; 3136]`. Данных недостаточно, чтобы утверждать, что среднее превышает ориентир 3130 м (`p = 0,928`).
- Средняя месячная выручка на пользователя у `Ultra` — 363,07 руб., у `Free` — 329,13 руб. Разница 33,94 руб., 95% ДИ `[28,77; 39,11]`, скорректированный p-value `1,00e-35`, Hedges' g `0,63`.
- Эмпирически 3,3% поездок `Ultra` длятся более 30 минут, а 34,0% — от 20 до 30 минут. Нормальная модель даёт 2,0% и 37,7% соответственно, поэтому для операционных порогов надёжнее эмпирические квантили.

## Что исправлено относительно учебного решения

- Оплачиваемые минуты округляются вверх через `ceil`, а не обычным `round()`.
- Невозможные поездки выявляются через расчётную скорость и исключаются до анализа.
- Статистические тесты выполняются на уровне независимых пользователей, а не связанных поездок одного человека.
- Для сравнения двух групп используется t-тест Уэлча без предположения о равенстве дисперсий.
- Помимо p-value рассчитаны доверительные интервалы и размеры эффекта.
- К трём гипотезам применена поправка Холма.
- Теоретические вероятности по нормальному распределению сопоставлены с фактическими долями.
- Формулировка теста про 3130 м согласована с направлением альтернативы: проверяется риск превышения порога.

## Методы

- очистка и валидация объединений `pandas`;
- анализ аномалий по расчётной скорости;
- агрегация выручки на уровне «пользователь — месяц»;
- односторонние t-тесты Уэлча и одновыборочный t-тест;
- 95%-е доверительные интервалы;
- Hedges' g и стандартизированный одновыборочный эффект;
- поправка Холма на множественные проверки;
- CDF/PPF нормального распределения и эмпирические оценки.

## Ограничения

Исследование наблюдательное и не доказывает причинный эффект подписки. Выручка рассчитана по тарифной формуле, без фактических транзакций, возвратов и затрат. Для оценки инкрементальной прибыли от продвижения `Ultra` нужен A/B-тест.
